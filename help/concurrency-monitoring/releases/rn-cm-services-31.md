# Adobe Concurrency Monitoring Services 3.1 リリースノート {#cm-services-rns}

このページでは、このリリースの新機能、変更点、既知の問題について説明します。

## リリース情報 {#release-info}

バージョン：3.1

リリース日：2020年9月3日（PT）

## リリースの概要 {#release-overview}

* 新しい同時実行レベルレポート。 このレポートには、同じアカウントの同時アクティブストリームの数が時間枠内で反映されます。 アクティブストリームは、正常に開始されたストリームとして定義されます。
* 新しいアクティビティレベルのレポート： このレポートには、アクティブなストリームと、ポリシーの適用後にストリームの初期化の試行が拒否されたという時間ウィンドウ内のユーザーのアクティビティが反映されます。
* このリリースでは、新しいレポートをリリースするプロセスを簡素化する内部の機能強化が行われます。
* 2020年5月に起動された内部REST Configuration APIを使用する新しい内部構成管理UI。
* 新しい構成管理UIを容易にするために、REST設定APIに対するさまざまなバグ修正と機能強化が行われました。

## 既知の問題

なし。
