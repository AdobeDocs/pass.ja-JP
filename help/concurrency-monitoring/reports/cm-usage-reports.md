# 同時実行モニタリング使用状況レポート {#cm-usage-reports}

>[!NOTE]
>
>このページのコンテンツは、情報提供のみを目的として提供されています。 このAPIを使用するには、Adobeの現在のライセンスが必要です。 無断使用は認められません。



## 概要 {#usage-rep-overview}

**同時視聴数モニタリング使用状況レポート** サービスは、お客様のアプリケーションによって報告された同時使用にinsightを提供するREST APIを介して利用できます。

## 前提条件 {#usage-rep-prerequisites}

同時視聴数モニタリング使用状況レポート製品にアクセスするには、お客様は最初に同時視聴数モニタリング [ サポートチーム ](mailto:tve-support@adobe.com)に連絡する必要があり、API製品へのアクセスを許可するために必要な手順を実行します。 [CMU API アクセス ](/help/concurrency-monitoring/reports/cmu-api-access.md)の詳細。

## 一般的なレポート指標と内訳 {#general-rep-metrics-breakdown}

### 使用状況レポート ユーザーは次の指標を監視できます。{#monitor-metrics}

| 名前 | 説明 |
|:---|:---|
| active-users | 期間の間に少なくとも1つのストリーミングセッションを開始した個別のユーザーアカウントの数（時間の精度で分類） |
| active-sessions | インターバル中にアクティビティを報告したストリーミングセッションの数（失敗した試行、初期化呼び出しの拒否レスポンスを受け取ったセッションは含まれません） |
| started-sessions | 期間内に開始されたストリーミングセッションの数 |
| completed-sessions | インターバル中に終了したストリーミングセッションの数（明示的またはタイムアウトのため） |
| 失敗した試行 | 拒否レスポンスを受信したセッション初期化の試行回数 |
| dismissed-sessions | ポリシー違反により、再生中（ハートビート上）に終了したストリーミングセッションの数。 この指標は、FIFOまたはlast_one_wins ポリシーが適用されている場合にのみ意味があります。 |
| キルドセッション | 新しいセッションの開始時に明示的に強制終了されたストリーミングセッションの数（X-Terminate ヘッダー経由） |
| duration_0-15 | 0 ～ 15分の間の期間を持つストリームの数 |
| duration_15-30 | 15分から30分の間のストリーム数 |
| duration_30-60 | 期間が30 ～ 60分のストリームの数 |
| duration_60-120 | 60分から120分の間のストリーム数 |
| duration_2h-4h | 2時間（120分）から4時間の間のストリーム数 |
| duration_4h-8h | 4時間から8時間の間のストリームの数 |
| duration_8h-16h | 8時間から16時間の間のストリームの数 |
| duration_16h-1d | 16時間から1日（24時間）までの期間を持つストリームの数 |
| duration_1d-3d | 1日から3日までの期間を持つストリームの数 |
| duration_3d-7d | 3日から7日間の期間を持つストリームの数 |
| duration_1w-1m | 1週間（7日間）から1か月（30日間）の期間を持つストリームの数 |
| duration_over-1m | 1か月（30日間）の期間を持つストリームの数 |

### 使用状況レポート ユーザーは、上記の指標を次のディメンションでフィルタリングできます。 {#dimensions-2-filter-metrics}

| Dimension名 | 説明 |
|:---------------|:------------------------------------------------------------------------------------------------------------------|
| 年 | 4桁の年 |
| 月 | 月（1-12） |
| 日 | 月の日（1-31） |
| 時間 | 時間帯 |
| 分 | 時間の分[^1] |
| アプリケーション | セッションの管理に使用する同時視聴数モニタリングに登録されたアプリケーション名 |
| application-id | セッションの管理に使用する同時視聴数モニタリングに登録されたアプリケーション ID |
| チャネル | セッションの初期化中に送信されたチャネルメタデータ（メタデータが送信されない場合は「不明」とマークされます） |
| mvpd | MVPDのセッション管理ツール |
| platform | セッション初期化時に提供されるか、設定レベルでアプリケーション用に事前定義されたプラットフォームメタデータ |

## 同時実行レポート指標と内訳 {#concurrency-reports-metrics-breakdown}

同時実行モニタリング バージョン 2.9.0以降、同時使用を理解するための新しいレポートが導入されました。**同時実行レベル**&#x200B;と&#x200B;**アクティビティレベル**&#x200B;のヒストグラムです。

このレポートの主な目的は、特定の同時実行数の制限を設定したポリシーの影響を理解し、制限を上げるかどうかを決定するのに十分な情報を提供することです。

### 使用状況レポート ユーザーは次の指標を監視できます。 {#metrics-usage-rep-users}

| Dimension名 | 説明 |
|:---|:---|
| ユーザー | 同時実行/アクティビティレベルに達したユーザーの数 |

### 使用状況レポート ユーザーは、上記の指標を次のディメンションでフィルタリングできます。 {#dimensions-to-filter-metrics}

| Dimension名 | 説明 |
|:---|:---|
| 年 | 4桁の年 |
| 月 | 月（1-12） |
| 日 | 月の日（1-31） |
| 同時実行レベル | ユーザーが開いた同時ストリーム **の数**&#x200B;を確認し、特定の同時実行制限を適用した影響を把握するために、ユーザーのセッション初期化フェーズ **で承認された個別の** ストリームアクティビティを表します |
| アクティビティレベル | ユーザーが開こうとした同時ストリームの数を確認し、特定の同時実行制限を適用した影響を把握するために、ユーザーに対する独自の&#x200B;**ストリームアクティビティ（状態に関係なく、開始、アクティブ、停止、拒否）を表します** |
| mvpd | MVPDのセッション管理ツール |

[^1]：分単位のレポートはデフォルトでは使用できません。 同時視聴数モニタリング [ サポート チーム ](mailto:tve-support@adobe.com)に連絡して、リクエストしてください。
