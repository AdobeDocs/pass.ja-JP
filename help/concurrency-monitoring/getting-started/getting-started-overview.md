# 同時視聴数モニタリングの概要 {#getting-started-overview}

同時視聴数モニタリングへようこそ！ このガイドでは、基本を理解し、迅速に統合を開始する方法を説明します。

## 同時視聴数モニタリングが解決する課題 {#problem-solved}

今日のストリーミング環境では、加入者は複数のデバイスやアプリケーションをまたいでコンテンツにアクセスできることを期待しています。 しかし、これはコンテンツプロバイダーにとって次のような課題をもたらします。

- **コンテンツライセンス契約**&#x200B;では、同時ストリームの数が制限されることが多いです
- 同時使用が過剰になると&#x200B;**帯域幅コスト**&#x200B;が増加
- **ユーザーエクスペリエンス**&#x200B;は、ストリームが多すぎるとパフォーマンスが低下します
- **収益保護**&#x200B;では、アカウント共有の不正使用を防ぐ必要があります

同時視聴数モニタリングは、これらの課題を一元的に解決します。


## 同時視聴数モニタリングの仕組み

### コア機能

同時実行モニタリングは、次のような&#x200B;**セッション管理サービス**&#x200B;として動作します。

1. **すべてのアプリケーションでアクティブなストリーミングセッション**&#x200B;をリアルタイムで追跡します
2. **現在の使用パターンに対してビジネスポリシー**&#x200B;を評価します
3. ポリシーに違反した場合、**制限を適用**
4. **競合が発生したときに解決オプション**&#x200B;を提供します

## 関係者の利点

### コンテンツプロバイダー（プログラマー）

- **コンテンツの権利を保護**&#x200B;し、ライセンス契約に準拠する
- **過度な使用を防止して帯域幅コストを最適化**
- **制限に関する明確なフィードバックにより、ユーザーエクスペリエンス**&#x200B;を改善する
- 詳細なレポートを通じて&#x200B;**利用状況に関するインサイトを取得**

### ID プロバイダー（MVPD）

- **すべてのコンテンツパートナーで購読者契約を適用**
- 複数のアプリケーションの&#x200B;**一元化されたポリシー管理**
- 使用パターンの&#x200B;**リアルタイム監視**
- **スケーラブルアーキテクチャ**&#x200B;数百万セッションを処理

### エンドユーザー

- **使用制限について**&#x200B;明確に理解する
- すべてのアプリケーションで&#x200B;**一貫したエクスペリエンス**
- **制限に達した場合に競合を解決するオプション**
- アクセスが制限されている理由に関する&#x200B;**透明性のあるフィードバック**

## サービス登録 {#service-registration}

同時視聴数モニタリングを開始するには、次の情報を[&#x200B; サポートチーム &#x200B;](mailto:tve-support@adobe.com)にお問い合わせください。

1. **会社名**&#x200B;と連絡先の詳細
2. 同時実行モニタリングと統合する&#x200B;**アプリケーション**。 アプリケーションごとに、次の情報を提供してください。
   1. アプリケーション名
   2. アプリケーションプラットフォーム
3. **統合パートナー** （別のパーティ、プログラマー、またはMVPDのリクエストで同時視聴数モニタリングを購読している場合）
