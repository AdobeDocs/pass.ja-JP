# Adobe Pass Authentication iOS / tvOS 3.9.2 リリースノート {#ios-tvos-sdk-392-rn}

>[!IMPORTANT]
>
> [製品のお知らせ](/help/authentication/product-announcements.md) ページに集計されている最新のAdobe Pass認証製品のお知らせと廃止予定について、常に情報を得てください。

このページでは、このリリースの新機能、変更点、既知の問題について説明します。

## ビルド番号 {#build-number-392}

Adobe Pass Authentication: iOS / tvOS 3.9.2

リリース日：**03/26/2024**

## リリースの概要 {#relaese-overview-392}

* IOS 17のプライバシー要件に準拠して、SDK Privacy Manifestを更新します。
* 認証フロー中にユーザーが空白の画面のままになる場合がある問題を修正しました。
* デバイスロギングとサーバーロギングを追加して、キーチェーンのステータスに関するinsight情報を取得します。

## リリースパッケージ {#release-package-392}

IOS/tvOS SDK v3.9.2は、[ここ](https://tve.zendesk.com/hc/en-us/articles/204963209-iOS-tvOS-Native-AccessEnabler-Library)からダウンロードできます。
