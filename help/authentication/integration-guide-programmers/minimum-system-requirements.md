# 最小必要システム構成 {#minimum-system-requirements}

>[!IMPORTANT]
>
>このページのコンテンツは、情報提供のみを目的として提供されています。 このAPIを使用するには、Adobeの現在のライセンスが必要です。 無断使用は認められません。

このドキュメントでは、サポートされているプラットフォームにAdobe Pass認証の統合を実装するための現在の要件について説明します。

以下に示すブラウザーおよびオペレーティングシステムは、合意されたSLAに拘束されるAdobe Pass Authentication Teamのサポートを受けることができます。 最新の安定したバージョンのブラウザーとオペレーティングシステムを使用して、パフォーマンス、効率性、セキュリティの向上に加えて、潜在的な問題に対するAdobe Pass Authenticationの完全なサポートを利用することをお勧めします。

また、現在使用されている古いブラウザーやオペレーティングシステムの存在も確認しています。 これらの古いデバイスは、問題なく機能する可能性がありますが、エラーが発生しやすくなります。 これらの古いプラットフォームで発生する問題を軽減するための最初のアプローチは、OS バージョン、ブラウザーのバージョン、またはインストールされているアプリケーションのバージョンである最新バージョンにアップグレードする必要があります。 これらのプラットフォームで発生した問題は、Adobe Pass認証チームがベストエフォートベースで対処します。

## ブラウザーとオペレーティングシステムの要件 {#browser-OS-system-requirements}

| Web/モバイルブラウザー（†） | サポートされているバージョン |
|------------------------------|--------------------|
| Google Chrome | **90**&#x200B;以降 |
| Mozilla Firefox | **57**&#x200B;以降 |
| Apple Safari | **16**&#x200B;以降 |
| Microsoft Edge | **110**&#x200B;以降 |

>[!IMPORTANT]
> 
> Adobe Pass Authenticationは、プライベートモードまたはシークレットモードを使用しないようにアドバイスします。

| オペレーティングシステム | サポートされているバージョン |
|---------------------|------------------------------|
| *Android* | **7.0** （Nougat）以降 |
| *iOS* | **14**&#x200B;以降 |
| *iPadOS* | **14**&#x200B;以降 |
| *tvOS* | **14**&#x200B;以降 |
| *Fire OS* | **5 （Android 5.1）**&#x200B;以降 |
| *Mac OS* | **10.13**&#x200B;以降 |
| *Microsoft Windows* | **10**&#x200B;以降 |

>[!IMPORTANT]
>
> Adobe Pass認証の使用権限フローは、ブラウザー設定が変更された場合、サードパーティ Cookieが無効になっている場合に失敗することがあります。
> 
> <br/>
> 
> Adobe Pass認証の使用権限フローは、デフォルトのブラウザー設定で機能します。
