# Adobe Pass認証サーバーサイドデータのAdobe Analyticsへの統合

>[!NOTE]
>
>このページのコンテンツは、情報提供のみを目的として提供されています。 このAPIを使用するには、Adobeの現在のライセンスが必要です。 無断使用は認められません。

Adobe Pass Authenticationをご利用のお客様は、Adobe Pass Authentication （Adobe Pass）サーバーサイドのデータをAdobe Analytics ダッシュボードで確認して、簡単に利用できるようにしたいと考えています。

このデータは、MVPDごとの認証コンバージョン率、MVPD ユーザーIDに基づくユニークユーザーなど、重要なTVE指標を追跡するのに役立ちます。

訪問者IDがない場合は、以下の特定のイベントを超えてユーザーアクティビティを追跡できないため、既に存在する場合は、クライアントサイド実装を置き換えることはできません。 お客様がPass呼び出しで訪問者IDを提供している場合、既存のお客様データを使用してすべてのPass イベントを結合できる別のタイプのAnalytics統合（リアルタイム）のロックを解除できます。この新しいタイプの統合について詳しくは、こちらを参照してください。「[Adobe Pass Authentication](/help/authentication/integration-guide-programmers/features-premium/analytics/exp-cloud-id-authn.md)」でのExperience Cloud IDの使用

## 詳細 {#details-int-authn-analyt}

* 指標は、Adobe Analytics Data Insertion APIを介して、特定のレポートスイートにイベントごとに挿入されます
* 挿入はバッチ処理され、30分ごとに送信されます。 このため、レポートにはタイムスタンプが必要です
* 各顧客には、1つまたは複数のレポートスイートがあります。 1つの依頼者ID （チャネル）は、1つのレポートスイートにのみマッピングされます。 複数の依頼者IDは、1つのレポートスイートにのみマッピングできます。
* 過去のデータを提供することはできますが、トラフィック/パフォーマンスに関する懸念により、特別な注意が必要です。
* 一意の訪問者変数は、MVPD ユーザーIDに設定されます
* イベントとeVarのマッピングは設定できません。
